## 4. 观察与如实标注

- **合成 suite 只用于机检**：Checks 八工作台面场景经 suite_runner 缝注入合成报告（上游 eval 用例 fixture 防递归同理）；**真实检查面 = delivery-serve 缺省 suite（客户 purchase_requires_approval 子进程照跑）+ 受控实验全链承载**——两者在证据链上分层可见。
- **教学替身**：实验拍③ reviewer = `TEACHING reviewer（教学替身——真实具名验收 = 用户按讲义 §4）`——不冒充真实人审。
- **异步诚实**：Checks `l13_task_api_accept` 以 latch 钉死「202 先于 Eval 完成」；实验拍①②（evaluating 中间态可观察 → review）互证。
- **D1 不采纳清单落账**：上游 workbench/ 后期增量（frozen contract v0 spec_text 面、agent_runner 缝、graphs HTTP 面 = workflow_graph 治理层）、course-status 等其余命令、initiatives/backups/projects/web_execution/daily/desktop、capabilities 的 code_execution 簇字段——均不在 L13 绑定 eval 断言面，未建（讲义 D1/Out of Scope）。
- **views 面裁剪**：稳定只读投影（schema `workbench.delivery-view/v1`）；完整面板投影（freshness/控制面）= L14 增量。
- **L14 因果交接就位**：capabilities / status_url / view_url 三个查询面即 L14 面板数据源。
