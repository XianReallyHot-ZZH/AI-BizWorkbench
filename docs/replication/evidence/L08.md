1. **B Run attempt 1（平台，36826158603）**——Maven Central 瞬时解析失败（`maven-resources-plugin could not be found`），Build 未过即 Job 红，注入/统一入口全 skipped：**非业务红**，受控对照被破坏。处置：rerun（attempt 3）Build 成功、唯一失败步骤 = 统一入口——可信红恢复；attempt 史留在平台 Run 页与 runs.json。

3. **`b4d27496`（rc 1）**——audit.py 首采：基线条目声明期望 decision 但未下载原件（目录缺失路径只 append 不打印，隐形失败）。处置：下载基线 artifact（六 Run 五原件全覆盖）+ 补打印；重跑 `2fc800f2` rc 0。留痕不导入。
4. **verify execution 7/8（任务账内，如实）**——execution 7：eval-command classpath 相对路径（workspace cwd 下 `target/classes` 失效 → ClassNotFoundException）；execution 8：`$(cat …)` 转义成字面传入（task-run 不经 shell 展开 → Jackson 缺失）。处置：构造时本地展开内联绝对 classpath，execution 9 verify_completed。两次失败记录保留在任务账。
5. **InjectDefect `.git` 文件泄漏（真实现缺陷，test-first 修）**——copyTree 只排除 `.git` **目录**，客户 submodule 的 `.git` 是**文件**（gitdir 指针）被拷入 → 链树 git init 后 `add -A` fatal（现场 = verify 前置失败首因）。合同测试假树首版无此文件未抓住。处置：测试补假 `.git` 文件（红）→ copyTree 排除 `.git` 文件（绿）16/16。已采 CI Run 不受影响（Run 红绿来自 sales.py 注入，SalesChecks 不做 git 操作）。
6. **status 首跑链判定失败**——`same_command_red_diff_green_missing`：record 74（工具链 mvn 红）导入任务账违反 JD7 先例（L07 工具链红/绿随分支不入账），mvn 红无同命令绿、链不闭合。账本只追加不可删。处置：按链规则补全工具链链（diff `699e8936` record 79 + 新采 mvn 绿 record 80，observed_at 递增），§5.5 裁量披露。

## 5. 执行期裁量与偏离披露

1. **`Cli.runMainWithIsolatedEnv` 扩展**（commit 1）：CI 环境父进程自带 `GITHUB_*` 变量，追加式注入无法构造「缺失身份」红面——新增隔离环境子进程缝（独立方法名，J2 两可教训；既有方法行为零变化）。
2. **CI 不跑 mvn 测试面（D1 偏离）**：终态合同测试断言工作流无吞失败旗子，与 A/B 教学态**自指冲突**（A 态 Run 里 mvn test 必红）。工作流以 `mvn -q process-test-classes` 构建替代（编译 + classpath 落盘），全量 `mvn test`（含 golden 六重放）留本地与验收门；CI_GATE_SPEC.md §门定义披露。venv 步骤随之不需要（CI 不跑 EvalHarnessContractTest）。
3. **链树形态（D5 细化）**：链树 = InjectDefect 拷贝产物（与 CI 同一装置同一构造），无版本簿记——diff 证据 = 与 vendors 源件对 diff，恢复 = 源件拷回 + 字节级指纹复核（强于 git checkout）；净 clone 仅作验净对账（eval 双树 = L07 冻结值）。verify 需 HEAD → 树内 git init + 起点封存提交（净态起点 `544563b`，业务链证据不受影响——基于指纹与封条）。
4. **A/B/C 的 B→C 形态**（D4 预披露的落实）：上游学生 B→C 修产品代码，本仓库 C = 移除注入装置（装置在场=缺陷在场）；分支历史 commit 2 终态 → 3 A → 4 B → 5 C（diff 0 行回终态）→ 受控对照三 diff 各只动一层，闭合验证在案。
5. **工具链链补全（§3.6 处置）**：record 74 误导入（违反 JD7 先例「工具链封条随分支不入任务账」）→ 账本只追加，按链规则补 diff（record 79）+ mvn 绿（record 80）闭合同命令链；偏离与处置如实入账。
6. **audit.py 入库**：复验者对账脚本随采集根入库可独立重跑（上游「下载报告核对版本与实际出口」的复验面工程化）；runs.json = `gh run list --json` 采集的平台元数据快照。
7. **mvn 工具链绿封条 `4b3d5d05`（commit 2 时点）随分支不入账**（JD7 口径保持）；链补全的 record 80 是修复 InjectDefect 后的新采绿（时序在 diff record 79 之后，递增成立）。
