# 0006 - 工作台实现语言切换为 Java，全量重走 L01–L06

复刻以 Python 跟跑上游（L01–L06 已具名验收），但验收人是生产级 Java 开发者、Python 非其可读语言：具名验收退化为"看 AI 自述签字"，日常维护不敢改代码——工作台"日常可用"的定位下，读不懂的实现是负债。决策：**全量换 Java 重走 L01–L06**，每讲按原讲合同走候选分支 + 起始红 + 具名验收；Python 版冻结为对照基准直至 L06 重走验收完成，之后退役（git tag + 移出工作树；历史与证据账只追加、不重开）。

**Why**: 课程自己声明"合同 = 验收接口，实现可换"（大纲挑战线先例：换 LangGraph 保持验收接口不变；ADR-0002 先例：换执行器保持合同形状同形）——这门课教的是方法与合同，不是 Python。用户痛点逐项核实全部是语言绑定（验收读不懂、脱离 AI 写不出、生态噪音挤占带宽、不敢改日常排障），课程概念本身已掌握；换语言直接修复验收机制的治理洞。时间预算不设限，付得起每讲翻译对照成本。

**Considered**: (a) 从 L07 起换 Java 不回头——Java 版要踩在验收人读不懂的 Python 信用内核上，治理洞原样保留，否决；(b) 长期双轨双实现——两个真相、维护×2，否决；(c) 继续 Python + 学习法改良——学习效果差已被实践证明，且验收机制持续被架空，否决。

**Consequences**:

- **载体锁定**：Maven + Java 21 LTS + JUnit 5（+AssertJ，测试侧）。运行时依赖白名单制，首批仅 Jackson（JDK 无 JSON）与 sqlite-jdbc（SQLite 驱动）；CLI 解析手写，对齐上游 argparse 的朴素度。白名单扩员须修订本 ADR。
- **合同 fixture**：以 Java 常量类承载，配完整性机检测试保证**字符串内容逐字等价**；铁律 4 的"逐字拷贝"随之改述为"逐字等价的数据内容 + 机检锁定"。
- **证据链**：封条本为语言无关 JSON 契约（meta.json 字段 + SHA-256 重算），采集/导入语义以 Java 复刻（L01 重走交付物之一），封条字段逐字段保持；vendor 工具仍只执行不修改。
- **验收门增量**：golden 字节级对照——冻结 Python 版代表性场景输出为对照基准，Java 输出逐字节一致；时间戳等不可复现字段在冻结时排除。
- **讲义**：原 L01–L06 讲义是对照基线，不重写；每讲追加"Java 移植注记"附录记录翻译点与偏差。
- **flowERP 驱动缝不变**：子进程 + JSON 报告 + 退出码，语言无关，客户真理照旧。
- **roadmap** 增设 Java 重走状态线（L01–L06 完成标注不回退，是历史事实）；L07 顺延至重走完成后。
