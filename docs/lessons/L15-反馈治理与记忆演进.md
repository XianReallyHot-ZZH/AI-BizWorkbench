## 1. 讲解

### 1.1 本讲要什么

L13 把交付封装成 Task 资源并沉淀了反馈账（Feedback 三 API 上游同形）；L14 把投影立住并在 DeliveryView 预埋了 feedback 块与 pending_feedback 计数（evolution 块 D4 明示「L15 按断言面增量补块」）；支线 S01 在 Python 时代建成七命令记忆闭环，但当年明确推迟 feedback/evolution 两级前置账（S01 §2/D2「待建设」），Java 对应物亦待建。本讲把这条链收拢成闭环——**反馈先审核才立项、经验经治理才入记忆、检索带引用才进上下文、改进留升级前后证据才算交付**。四个增量面：①**演进记录 EvolutionStore 全链**（真新面：反馈审核闸门 + 六状态机 + verify 重门含 learning/ 资产 governed 分支）；②**记忆系统 Java 对应物**（S01 冻结面七命令五表重走 + evolution 来源级联增量——「Memory/RAG」的最小实现：元数据过滤、可解释排序、字符预算 Top-k、采用快照、撤回/跨项目隔离）；③**L14 预埋补块**（DeliveryView evolution 块 + 第九计数 verified_evolutions）；④**动态 Eval 机制**（首见：本次新增 eval 用例必须先真实失败——起始红在课程合同里的形式化，与候选分支 commit 1 同构互证）。

上游钉死的判断，本讲全链贯穿：**未审核反馈不得提升为进化记录**（evolution.create 词面「只有具名接受的反馈才能提升为进化记录」）；**接受也不等于改写裁判**（EVALS 里 receiving_is_idempotent 仍 blocking——反馈与检索结果无任何直接改写阻断 Eval 的通道）；**进化必须由下一项独立交付任务验证，不能复用源任务**（verify 词面）；**记忆来源快照封存 + 每次读取重算 sha256**（内容漂移阻断，不静默）；**撤回/被替代不删除只状态迁移**（与铁律 3 同构）；**检索不到如实为空**（不编造召回）；**操作人必须具名人工**（human() 词面拒 ai/codex/system/claude/待确认/待定/tbd/pending/agent:*——S01 增补 claude，更严）。

### 1.2 业务案例：反馈到复验五拍（REQUIREMENT:COURSE-L15）

合同描述原文即链路剧本：①**采集**——使用者对已交付事项提真实反馈 → `add_feedback`（FB-*，pending_review；L13 失败自动沉淀的观察反馈同入此账）；②**审核立项**——具名 `review_feedback` accept → `evolution create`（proposed，失败签名 + 五分类 + business_refs）→ `evolution review` approve → `evolution assets` 登记版本化资产变化（type/path/reason）；③**记忆登记**——已审核经验 `learn-create`（来源准入：已验收任务，或**已接受失败反馈对应的 Evolution**——L15 新入口；来源快照整体封存记 sha256）→ `learn-govern` 具名 approve/publish（同 family 旧版本原子 superseded）；④**检索采用**——在另一事项 `learn-recall`（项目过滤 + 仅 active + applies/excludes 命中 + 可解释排序 + 字符预算 Top-k + 冲突显式分组；召回包整体落库 RECALL-*）→ `learn-bind` 逐项采用决定（采用资产全文快照封 BIND-*，plan/task 双唯一）→ `learn-run`/`learn-finish` 五相位复验（outcome=passed 须具名验收，缺则「复用验证缺少具名验收」）；⑤**交付验证**——改进任务经 delivery 链交付（升级前红 → 升级后绿）→ `evolution verify`（候选任务 ≠ 源任务、共享 business_ref、逐项 blocking + 报告 sha256 重算 + governed 分支：登记的 learning/ 资产须有绑定与 outcome passed）→ 面板 evolution 块与 verified_evolutions 计数可见。「交付摘要」上游无独立模块（course_delivery/course_release/automation grep「摘要」零命中）——由 L14 view 投影 + 本讲 evolution/feedback 补块承载，如实落账不新建面（D7）。
