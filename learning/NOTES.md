# 教学笔记（Claude 工作底稿）

- 语言：中文。术语给中文 + 必要时括注英文词面（与上游错误词面对齐）。
- 节奏：每课一个窄点，10 分钟内；用户时间碎片化，课要能断点续学。
- 偏好确认过的循环：讲解 → 用户亲手跑命令/复验 → 对照结论。教学设计尽量复刻这个循环。
- 用户身份双重性：既是学习者也是验收人——课程选题优先服务"下一次验收更懂行"。
- 已确认的教学区决策（2026-09-26）：使命 = 读懂并验收本工作台；工作区 learning/ 入库。
- 第一课（0001）选"证据链判定"：直接训练验收技能，且是用户刚在 L01 验收中真实用过的判断。
- 第二课（0002，2026-09-27）选"L03 闸门语义与屏蔽算法"：用户刚具名验收 L03 并主动要求讲解——趁热建"解析器只管结构"的判断力，直接服务 L04 验收（执行器吃 Spec 干活，闸门语义要脱口而出）。课内含预测→运行三份输入的亲手复验块与 4 题判分测验；0001 的链判定测验仍未作答，按间隔重测原则不催、不并入本课。
- 第三课（0003，2026-09-27）补 L02 同款分析，用户点名。选题收窄为"规则生效的证明"——L02 几乎无新代码，教学点是 N0/N1 对照归因 + 三层分检（在场/行为/程序互不替代），复验块改为"跑 test_l02 + 肉眼对照 N0/N1 实物"。与 0002 互为左右邻：L02 长期规则画围栏、L03 单次合同定目标，L04 验收的两个追问模板（"证据在哪层？""唯一自变量是什么？"）分属两课。
- 第四课（0004，2026-09-27，L04 验收后用户点名讲解意图/机制/代码）。教学点收窄为"笼子怎么关住造笼子的物种"：执行器合同五要素的"事前声明/事后实测/如实限制"三层 + 状态派生（复核按 execution_id 匹配）。教材全部取自当天真实产物——三处实跑缺陷（nargs 接口、预算门、launch error 丢记录）与 eval V1 误报就是课件的失败案例库。测验 4 题全是 L04 真实情境。复验块 = workbench-task-show 读一败一成两条执行记录 + status 链。预告 L05 的引子："检查器自己会错吗"。0001/0002 测验仍未作答，不催不并入。
- 第五课（0005，2026-09-28，S01 验收后用户点名讲"做什么/目的/解决什么问题/代码"）。教学点收窄为"两套链的分工"：红绿链判时序（只服务任务证据账）、sha256 快照链判内容不变（记忆账）+ 生命周期状态机失效不删除。代码四段全配 S01 真实故事：来源准入门、_check_source 读错层级空转（被 C5/C10 抓获）、召回管线"不命中都有去处"、防漂移与失效治理；时间戳事故入测验 Q4。复验块 = 只读两命令对主账真实资产（show v1 superseded + recall 只剩 v2）。0001/0002 测验仍未作答，不催不并入。
- 第六课（0006，2026-09-28，L05 验收后用户点名 teach L05）。教学点收窄为"检查器辨别力三问"：①检查谁（被测路径）②抓得到吗（缺陷基线两连红）③对什么盲（盲区对照）。教材全部取自当天真实产物：无效探针（事实真但层错→v1 翻案）、两连红同命令异树设计、账面重写盲区实验（客户 eval 绿×2/驱动红）、裸 assert 定位口径（复查轮纠正 traceback 失实）。三问收口成验收人的绿灯自证清单；上游辅导资料 §3"连续两次均失败+定位到具体要求"是知识主干。复验块三命令：亲手跑红（讲义 §4 人审门同款）、sqlite 只读查链 44–48、shasum 核指纹。0001/0002 测验仍未作答，不催不并入。
